# HACYBERGLOBALTECH - Legal & Compliance Portal

This repository contains the legal, compliance, and policy documentation for **HACYBERGLOBALTECH**, including the hosted Privacy Policy and Terms of Service.

## 📄 Included Documents

* **`privacy-policy.html`**: Detailed Privacy Policy describing data collection, third-party platform integration handling, payment processing security (Stripe), and user data retention policies.
* **`terms-of-service.html`**: Terms of Service detailing agreement conditions, service scope, payments, and limitation of liability.
* **`index.html`**: Main landing entry point for the portal.

## 🚀 Live Endpoints

The static pages in this repository are continuously deployed and accessible via the following production domains:

* **Business Website / Payment Portal:** `https://pay.hacyberglobal.dgdns.org/`
* **Privacy Policy:** `https://pay.hacyberglobal.dgdns.org/privacy-policy.html`
* **Terms of Service:** `https://pay.hacyberglobal.dgdns.org/terms-of-service.html`
* **Customer Support:** `https://hacyberglobal.dgdns.org/support`

## 🛠 Deployment

This project is configured for automated static deployment via web hosting platforms (Vercel / Cloudflare Pages / GitHub Pages). Any updates pushed to the `main` branch automatically deploy to production.
