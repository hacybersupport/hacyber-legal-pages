# Contributing to HACYBERGLOBALTECH Legal Pages

Thank you for your interest in contributing to our legal documentation repository!

## Guidelines

### Document Updates
- All legal documents must be reviewed and approved before deployment
- Changes to Terms of Service or Privacy Policy require legal review
- Use semantic HTML and maintain accessibility standards
- Ensure all external links are verified and up-to-date

### Branches
- Create feature branches for major updates: `feature/document-name`
- Use patch branches for minor corrections: `patch/issue-description`
- Keep commit messages descriptive and concise

### Code Style
- Use consistent HTML formatting
- Maintain responsive design patterns
- Ensure dark/light theme compatibility
- Test all links and navigation elements

### Pull Requests
1. Provide a clear description of changes
2. Reference any related issues or tickets
3. Ensure all links are working
4. Test responsive design on mobile/tablet/desktop

## Report Issues
Please report documentation errors or broken links by opening an issue with:
- Clear description of the problem
- Location in the document
- Suggested fix (if applicable)
